## 📌 平台核心架構與 6 大章節（共 29 頁高階簡報 · 頁頁均含圖表）

本決策平台嚴格依據《中山大學微電網建置統包工程需求說明書》全 16 份正式招標文件及《中山大學微電網標案_可行性評估.md》（v0.2 計畫書技術稽核交叉版）內部報告建構：

### 🏠 封面決策中樞 (Executive Overview)
- **西子灣天然孤島環境硬約束**：台電末端饋線、靠山面海、事故無法轉供。
- **六大量化關鍵指標**：
  - 有條件投標：可行性初判結論
  - 電氣設備台製限制：須知勾選原產地須我國，電芯無台產，若涵蓋電芯則一票否決
  - 安裝 vs 可用容量：3MWh 未定義 Installed 或 Usable，價差高達 600~900 萬
  - 9,200萬 vs 9,500萬：預算前後矛盾（超額即廢標）
  - 48h 缺口 8,656 kWh：250kW 連續 48 小時需柴油約 2,700L，柴發油箱與補給責任空白
  - 無上限求償：契約第 19 條未設賠償上限之重大法律曝險
- **GIS 校園地圖**：西子灣校區 6 處關鍵節點 GIS 標定。
- **五大多功能調度模式動態潮流模擬器**：併網超約抑制、尖離峰轉移、純儲能孤島 (≥4h)、雙源孤島 (SOC<30%)、防災留置 (≥48h) 與 Seamless 瞬切。

### 📑 Part 1：專案背景與評選 (5 頁)
- **P1.1 專案起源與西子灣天然孤島環境**（台電節能韌性示範、校地 73.4 公頃、建物 35 處）
- **P1.2 全校饋線系統與 GCB6 關鍵供電區**（十大饋線拓撲、國研 584kW 半導體關鍵負載分級表）
- **P1.3 儲能與微電網配置場域實勘分析**（排球場旁場地 13.2m×5.8m、2m 行人通道、C5-M 塗裝）
- **P1.4 統包工程工作範圍與權責矩陣**（設計施工全包、中國製資通訊產品嚴禁採用、台電 DREAMS 介接）
- **P1.5 投標評選須知 7 大評分維度與致勝關鍵**（最有利標序位法 7 大項目配分表、上限 60 頁）

### ⚡ Part 2：系統架構與機電 (6 頁)
- **P2.1 微電網總體架構與單線拓撲**（創、儲、控、耗、備五位一體高壓側併接）
- **P2.2 儲能系統 (BESS) 規格與五層防護體系**（三層鋼板岩棉櫃體防火1小時、細水霧、標檢局 VPC 認證）
- **P2.3 功率調節器 (PCS) 與微網控制器 (MGC)**（1200kW PCS、MGC 作為 OT 安全邊界節點、指令白名單）
- **P2.4 太陽光電創能佈局與風雨球場擴充**（國研頂樓 118kWp、海工停車場 295kWp、風雨球場最高 2,000kWp）
- **P2.5 雲地協同 EMS 能源管理平台**（可失聯降級、RESTful API 演算法注入空間、NAS 資料庫同步、資安弱掃/滲透測試）
- **P2.6 全校保護電驛協調與避雷接地優化**（全校保護協調報告、ABB REF-615 5台、消導雷器 11台、SPD 32台）

### 🔄 Part 3：運轉調度與維運 (5 頁)
- **P3.1 併網運轉調度：抑制超約與尖離峰轉移**（淨負載平滑化、契約容量 7,550kW 降至 6,550kW、調降 1,000kW）
- **P3.2 孤島與防災模式：4h 實驗保供與 48h 防災留置**（三階孤島接力：儲能孤島 → 柴發電流源 SOC<30% → 柴發電壓源 SOC<10%）
- **P3.3 Seamless 電力無縫接軌架構與波形分析**（市電故障無縫重建電壓源、市電恢復無縫同步併網）
- **P3.4 商業模式驗證與多重經濟效益**（綠電憑證 T-REC、台電輔助服務、EV 充電營運、時間電價差套利、外銷樣板）
- **P3.5 里程碑甘特圖、驗收與 5 年全責保固**（決標+14天簽約/計畫書、+40天細設、116/6/30報竣工、24/72 SLA）

### ⚠️ Part 4：契約與關鍵風險 (5 頁 · v0.2 更新)
- **P4.1 核心風險總覽：五大優先確認致命項**（電氣設備台製限制、3MWh容量未定義、損害賠償無上限、無物調、預算矛盾）
- **P4.2 法規與審批風險：原產地瑕疵、消防與台電併審**（須知第16點(2)子選項未勾選瑕疵、消防指引、台電併審）
- **P4.3 技術規格評估：48h防災柴油缺口、Seamless與Modbus資安**（2,700L柴油缺口、海工295kWp跨饋線、OT資安層150~300萬）
- **P4.4 履約工期壓力評估：40天細設扣減、儲能交期與竣工**（修正逾1次計工期、落後20%終止罰則、DIgSILENT模擬基準）
- **P4.5 商務財務與經費結構：計畫層級剖析與資金佔用**（整體計畫2.22億、台電補助1億為主要財源、LCC回收期約20年）

### 🎯 Part 5：可行性決策建議 (4 頁)
- **P5.1 三大可行性決策選項分析**（選項 A 全力搶標、選項 B 有條件投標【建議】、選項 C 放棄不標；增列電芯產地一票否決機制）

- **P5.3 組織橫向與縱向聯動矩陣**（往上牽動：董事會/財務額度/法務意見；往下推動：業務/設計搶跑/採購/運維）

### ❓ Part 6：標前釋疑與追蹤表 (4 頁 · 單獨新增)
- **P6.1 標前釋疑總體策略與 11 大問題分類看板**（採購法第41/43條時效、優先度矩陣、追蹤流程看板）
- **P6.2 致命合規與商務條款釋疑追蹤表 (Q1 ~ Q5)**：
  - Q1: 原產地限制「電氣設備須屬我國」是否涵蓋儲能電芯/電池櫃/PCS
  - Q2: 投標須知第 16 點(2)子選項均未勾選之文件瑕疵
  - Q3: 儲能 3MWh 係安裝容量 (Installed) 或可用容量 (Usable)
  - Q4: 契約第 19 條損害賠償責任是否增列以契約價金總額為上限

- **P6.3 工程邊界與容量定義釋疑追蹤表 (Q6 ~ Q8)**：
